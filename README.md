# Cloud Sea

An open-world 3D flying game in the browser: floating islands, a floatplane, a rideable dragon, on-foot exploring, villager errands and ring races. Built with Three.js.

## Play
Open `index.html` through a web server (for example GitHub Pages). No build step is needed.

## Multiplayer
Rooms use Claude's room service, which only works when the game is opened inside Claude. On GitHub Pages the game is single-player until a realtime backend is added.
